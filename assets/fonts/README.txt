StayNomad Typography Folder
===========================
Display Font: Fraunces (Optical Serif)
Body & UI Font: Manrope (Geometric Humanist Sans)

To self-host custom WOFF2 font binaries offline, place:
- Fraunces-Variable.woff2
- Manrope-Variable.woff2
in this /assets/fonts/ directory. CSS @font-face rules in assets/css/base.css automatically detect locally installed Fraunces and Manrope fonts and provide curated editorial serif and humanist sans system fallbacks with zero external network requests.
